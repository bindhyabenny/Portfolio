# Bindhya Benny - Developer Portfolio Website

A modern, minimal, and recruiter-friendly portfolio website designed for **Bindhya Benny**, **Flutter & Angular Developer** and B.Tech Computer Science & Engineering graduate.

## 🚀 Live Preview / Running Locally

You can open and test this portfolio locally in any modern browser:

### Option 1: Direct File
Simply open `index.html` in your web browser (e.g., Chrome, Edge, Firefox, Safari).

### Option 2: Local HTTP Server (Recommended)
Using Python:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your browser.

Or using Node/VS Code Live Server extension.
